## Resume-ready description

**Forecasting the Green Bond Index**

- Built a Python ETL workflow to extract and cache LSEG market data, integrate local S&P
  Green Bond Index exports, and audit missing values and duplicate dates with SQL.
- Engineered lagged market indicators and historical rolling features with training-fitted
  imputation and outlier handling for reproducible time-series modeling.
- Implemented ARIMA, Random Forest, and LSTM forecasting with chronological train,
  validation, and test splits and a last-value persistence benchmark.
- Added random and Bayesian hyperparameter search, dated forecasts, model comparison
  figures, and automated checks for feature leakage and preprocessing consistency.
